# Study.Table()

Десктопное приложение на **C++** и **Qt 6 (Widgets)** для учебного центра: пользователи, курсы, записи и оценки. Данные в **JSON** в папке `data/` (без СУБД). Курсовой проект по ООП, команда ~5 человек.

**Сборка и запуск:** см. [run.md](run.md).

**Команда из 5 человек:** кто за что отвечает при переписывании проекта — см. [TEAM.md](TEAM.md).

## Возможности

| Роль | Что делает |
|------|------------|
| Администратор | Пользователи, курсы, записи студентов на курсы |
| Преподаватель | Свои курсы, студенты, выставление оценок |
| Студент | Свои курсы и оценки, средний балл |

## Стек

- C++17, Qt 6, qmake (`StudyTable.pro`)
- Хранение: `QJsonDocument` + файлы в `data/`
- UI: виджеты в коде, стили — `resources/styles/main.qss`, ресурсы — `resources.qrc`

## Структура проекта

```
models/        User, Course, Grade, Enrollment
controllers/   Auth, User, Course, Grade
views/         LoginWindow, AdminPanel, TeacherPanel, StudentPanel
database/      DatabaseManager (singleton) — чтение/запись JSON
data/          users.json, courses.json, grades.json, enrollments.json
```

Идея: **MVC** (окна → контроллеры → модели; файлы только через `DatabaseManager`). Паттерн **Singleton** у менеджера данных — один объект на все обращения к файлам.
